# AWVS 服务管理工具包 - 使用说明

## 📋 工具概述

本工具包包含两个批处理脚本，用于简化 AWVS (Acunetix Web Vulnerability Scanner) 服务的日常管理操作。特别适合需要频繁启动和停止 AWVS 服务的渗透测试人员和安全研究人员。

### 包含文件

- **`Avwvs_Manager.bat`** - 完整的 AWVS 服务管理控制台
- **`Launch_AWVS.bat`** - 专用的 AWVS 服务启动脚本

---

## 🛠️ 脚本详细说明

### 1. Avwvs_Manager.bat - 完整管理控制台

#### 功能特点
- ✅ 完整的服务管理功能（启动、停止、重启、状态检查）
- ✅ 实时服务状态监控
- ✅ 用户友好的菜单界面
- ✅ 错误处理和状态反馈

#### 使用前准备
1. 将脚本放置在合适的目录（建议：`C:\Tools\AWVS\`）
2. 确认 AWVS 已正确安装且服务名称为：
   - `acunetix` (Acunetix Supervisor)
   - `Acunetix Database` (Acunetix Database)

#### 使用方法
**方法一：手动运行**
```cmd
# 右键点击脚本，选择"以管理员身份运行"
Avwvs_Manager.bat
```

**方法二：命令行指定操作**
```cmd
# 以管理员身份运行CMD，然后执行：
echo 1 | Avwvs_Manager.bat    # 启动所有服务
echo 2 | Avwvs_Manager.bat    # 停止所有服务
echo 3 | Avwvs_Manager.bat    # 重启所有服务
```

#### 菜单选项说明
| 选项 | 功能说明 | 使用场景 |
|------|----------|----------|
| **1** | 启动 AWVS 所有服务 | 需要使用时启动所有相关服务 |
| **2** | 停止 AWVS 所有服务 | 使用完毕后释放系统资源 |
| **3** | 重启所有服务 | 服务异常或配置更新后使用 |
| **4** | 检查服务状态 | 查看当前服务运行状态 |
| **Q** | 退出脚本 | 退出管理控制台 |

#### 预期输出示例
```
[信息] 当前服务状态：
    Acunetix Supervisor:   [运行中]
    Acunetix Database:     [运行中]
```

### 2. Launch_AWVS.bat - 专用启动脚本

#### 功能特点
- 🚀 一键启动所有 AWVS 服务
- 🔒 自动管理员权限检查
- 🌐 可选浏览器自动打开
- 📊 清晰的启动状态反馈

#### 使用场景
- 创建桌面快捷方式，双击即可启动 AWVS
- 集成到其他自动化流程中
- 快速启动环境进行安全测试

#### 配置桌面快捷方式（直接扔到桌面也行emmm）

**步骤 1：创建快捷方式**
1. 桌面右键 → 新建 → 快捷方式
2. 输入对象位置：
   ```
   cmd /k "C:\Tools\AWVS\Launch_AWVS.bat"
   ```
3. 命名快捷方式为 "启动 AWVS"

**步骤 2：设置管理员权限（重要）**
1. 右键新建的快捷方式 → 属性
2. 切换到"快捷方式"选项卡
3. 点击"高级"按钮
4. 勾选"用管理员身份运行"
5. 点击"确定"保存

**步骤 3：设置图标（可选）**
1. 在属性窗口中点击"更改图标"
2. 浏览选择 AWVS 的图标文件（通常位于安装目录）
3. 点击"确定"应用

#### 脚本执行流程
1. **权限验证** → 检查是否以管理员身份运行
2. **服务启动** → 按顺序启动两个 AWVS 服务
3. **状态反馈** → 显示每个服务的启动结果
4. **浏览器提示** → 询问是否打开 Web 界面
5. **结果确认** → 按任意键关闭窗口

## ⚠️ 重要注意事项

### 权限要求
- **两个脚本都必须以管理员身份运行**
- 否则无法启动/停止系统服务
- 建议通过快捷方式属性永久设置管理员权限

### 服务名称验证
如果脚本无法正常工作，请检查服务名称：
```cmd
# 在CMD中运行以下命令查看服务列表
sc query | findstr "Acunetix"
```

如果服务名称不同，需要修改脚本中的服务名称变量：
```batch
set "SUPERVISOR_SVC=你的实际服务名"
set "DATABASE_SVC=你的实际数据库服务名"
```

### 路径配置
- 确保脚本中指定的路径与实际安装路径一致
- 如果移动脚本文件，需要更新所有相关的路径引用

## 🔧 故障排除

### 常见问题及解决方案

**问题 1：脚本闪退或立即关闭**
- **原因**：未以管理员身份运行
- **解决**：右键脚本选择"以管理员身份运行"

**问题 2：服务启动失败**
- **原因 1**：服务名称不匹配
- **解决**：检查并修改脚本中的服务名称
- **原因 2**：AWVS 未正确安装
- **解决**：重新安装 AWVS

**问题 3：端口 3443 无法访问**
- **原因**：服务未正常启动或防火墙阻止
- **解决**：
  1. 使用选项 4 检查服务状态
  2. 检查防火墙设置
  3. 尝试重启服务（选项 3）

**问题 4：浏览器无法打开 Web 界面**
- **原因**：服务仍在启动过程中
- **解决**：等待 30 秒后刷新页面或重新打开
